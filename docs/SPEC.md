# AgroSim BBCH — специфікація

Навчальний симулятор фаз розвитку рослин за шкалою BBCH для основних культур України та інтерактивний тренажер із визначення фази.

**Культури MVP:** озима пшениця, кукурудза, соняшник, озимий ріпак, цукровий буряк. Друга хвиля: ячмінь, соя, картопля, горох, гречка (наявність шкали в монографії перевіряти окремо; в монографії є шкали для зернових, кукурудзи, ріпаку, соняшнику, буряку, картоплі, сої, гороху, бобів).

**Модулі:** Атлас фаз → Лінія розвитку (слайдер + SVG-рослина) → Тренажер «Впізнай фазу» → Польова діагностика (відбір рослин, інструменти, фаза поля за часткою рослин) → Щоденник сезону та звіт.

**Правило фази поля:** фаза поля оцінюється за часткою рослин, а не за однією рослиною. Єдиний поріг у джерелі: щонайменше 50% рослин досягли стадії (BBCH Monograph, 2-ге видання 2001, загальна частина; береться головне стебло; `ref-bbch-2001`). Порогів «початок/повна фаза» для зернових у джерелі немає, їх не вводимо; розмір вибірки в джерелі не нормується.
